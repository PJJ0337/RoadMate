## 3일차 — 2026-10-29 (목) · 핵심 흐름 구현 (예측 → 대화 → 안내 → 파워냅)
- SDK 소스·바이너리에서 실제 API 시그니처 확인 (문서 API 레퍼런스 본문이 비어 있어 직접 분석)
  - 주요 발견: 순정 졸음 경고등(Telltale) 조회·구독은 `PRIVATE_CAR_SAFETY`(signature|privileged) 권한 필요 → 일반 앱에서 막힐 수 있음. 경고등 없이도 운전 시간·크루즈·조작·무응답으로 판단하도록 설계
  - 주행 시간 단위는 '분', 기어는 Gear API(deprecated, AAOS GEAR_SELECTION 권장)
- 새 구조
  - `core/RoadMateBrain`: 4단계 상태 머신 (DRIVING → TALKING → GUIDING_TO_REST → NAPPING)
  - `core/DialogueScript`: 대사 모음 (다음 단계에서 LLM 대화로 교체 예정)
  - `car/VehicleMonitor`: 주행 시간·크루즈·기어·방향지시등·브레이크·졸음 경고등 구독
  - `car/VoiceIO`: TTS로 먼저 말 걸고, STT로 8초간 대답 대기 → 무응답 시 위험 점수 상승
  - `car/RestNavigator`: FusedLocation 현재 위치 → 가장 가까운 휴게소로 NaviHelper 길 안내
  - `car/CabinController`: 각성·낮잠·기상 모드 (공조·조명·시트 열선/통풍·등받이·창문 제어)
  - `MainActivity`: 상태 대시보드 + 시연 패널(운전 +30분, 졸음 경고, 기어, 대답 버튼)
- 단위 테스트 12개 통과 (위험 점수 5 + 4단계 흐름 7)
- ✅ 에뮬레이터에서 4단계 전체 흐름 동작 확인
  - 시연 패널(기어 D, 운전 +2시간, 졸음 경고) → 로드메이트가 먼저 음성으로 말 걸기
  - **실제 음성 대답 "쉬고 싶어"를 STT가 인식** → 서울만남의광장휴게소로 NaviHelper 길 안내 (10km·22분 경로 생성)
  - 기어 P → 낮잠 모드 → 30초 뒤 기상 모드 + 인사 음성
- 확인된 에뮬레이터 제약과 대응
  - 주행 시간(Odometer) ERROR_NOT_SUPPORTED_PROPERTY → 시연 버튼으로 대체
  - 공조·조명 제어가 운전석 영역(0x1) 미지원으로 실패 → Capability API로 지원 영역·값 범위를 먼저 확인하도록 수정
  - 창문 최소값(10) 위반 → 지원 범위 안에서 제어하도록 수정
  - 위치가 에뮬레이터 기본값(미국)일 때 거리 계산 무시
  - 음성·버튼으로 동시에 대답하면 안내가 두 번 실행 → 안내 중에는 중복 실행 방지
- 단위 테스트 13개 통과
- 안내 음성 볼륨 자동 조정(시연 모드 90%), 기상 모드가 끝나면 쉼터 길 안내 자동 종료 (에뮬레이터 Dyno Mode 표시가 남는 문제 해결)
- 길 안내 시작 시 내비게이션 화면 자동 표시 (NaviHelper requestNavigationScreen)

## 5일차 — 2026-10-30 · 가상 콘솔(Virtual Console) 연결 & 실제 차량 신호 검증
- `adb forward tcp:8088 tcp:8088` → http://127.0.0.1:8088/ 가상 콘솔 연결 (DDS ONLINE)
- 콘솔에서 기어 D/P를 바꾸면 앱이 실제 차량 신호로 반응하는 것 확인
  - D → 주행 감지 / P → 낮잠 모드 자동 시작 → 기상 모드
- 앱의 실내 제어가 가상 차량에 반영되는 것 확인
  - 각성 모드: 공조 ON, 20℃, 통풍시트 V2
  - 낮잠 모드: 24℃, 조명 어둡게
  - 기상 모드: 19℃, 풍량 6, 앰비언트 100%, 운전석 창문 20%, 통풍시트 V3
- 통풍시트 수정: 이 차량은 '시트 온도' 하나로 통풍(-3~-1)·열선(1~3)을 함께 씀 → 지원 범위를 확인해 맞는 방식으로 보내고, 운전석을 우선 선택

## 6일차 — 2026-11-01~02 · AI 대화 연결 & 이어지는 대화
- Pleos LLM SDK가 에뮬레이터 v2.1.0(10/19)부터 제공 종료된 것 확인 → 설명회에서 허용한 외부 API(Google Gemini)로 대체
- 이어지는 대화: 먼저 말 건 뒤 대답에 맞춰 같은 주제로 2번 더 묻고 3번째에 마무리 (대답할 때마다 깨어 있는지 확인)
- 두 겹 구조: Gemini 키가 있으면 AI 자유 대화, 없거나 4초 안에 응답이 없으면 내장 대본으로 대답 → 인터넷이 끊겨도 시연이 깨지지 않음
- API 키는 local.properties에서 읽어 저장소에 올라가지 않게 함
- 수정
  - "휴게소"라는 단어만 나와도 휴게소 안내가 시작되던 문제 → 쉬겠다는 뜻(졸려·쉬고 싶어·휴게소 가자 등)일 때만 안내
  - 졸음 경고가 켜진 동안 새 주제마다 같은 첫마디 반복 → "그럼 이번엔 다른 이야기 해 볼까요?"
  - 대화를 마무리하자마자 새 질문 → 마무리 시점부터 간격 두기
  - Gemini가 '생각'을 길게 해 응답이 늦거나 잘림 → 생각 최소 설정, 잘린 대답은 버림, 더 가벼운 모델(gemini-flash-lite-latest)
  - 공조 전원 직후 풍량 설정 실패 → 잠시 뒤 재시도
- 단위 테스트 23개 통과
